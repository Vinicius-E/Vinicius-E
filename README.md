## How I work

1. **Understand** the operational problem and the people who have it — not the feature list.
2. **Design** the simplest architecture that meets the real requirements, and make the trade-offs explicit.
3. **Build with evidence**: tests first, automated visual and accessibility gates, and attack probes against my own systems.
4. **Operate**: audit trails, idempotency, tenant isolation, limits — reliability is a feature.
5. **Evolve** from real use, not from guesses.
